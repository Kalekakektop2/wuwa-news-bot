# Бот настройки Discord

Один раз заходит на сервер и создаёт каналы, голосовые, роли и вебхук для новостей.

## Что сделает

- категории: ИНФО, ОБЩЕНИЕ, ИГРА, ГОЛОС
- текстовые: приветствие, новости, правила, общий, билды, русификатор, вопросы
- голосовые: Общий, Кооп, AFK
- роли: Админ, Модер, Игрок
- пост в `#приветствие` со ссылками на Telegram и GitHub
- вебхук в `#новости` для автопостов

## Как включить

1. Создай сервер в Discord.
2. Открой [Discord Developer Portal](https://discord.com/developers/applications) → **New Application** → имя `Wuwa RUS`.
3. Слева **Bot** → **Add Bot** → **Reset Token** → скопируй токен.
4. Включи **Public Bot**, остальное можно не трогать.
5. **OAuth2 → URL Generator**:
   - Scopes: `bot`
   - Permissions: `Administrator`
6. Открой получившуюся ссылку и пригласи бота на свой сервер.
7. Сюда пришли токен (и по желанию ID сервера). Я запущу настройку.

Либо сам:

```
DISCORD_BOT_TOKEN=...
python setup.py
```
