# Пикабу-бот для WuWa

Отдельный бот. В канал не пишет.

Официалка (патч, превью, техработы) уходит в Telegram и Discord сама, без «да/нет».
В личку приходит только черновик на Пикабу.

Плюс смотрит форумы игроков (Reddit). Если кто-то поставил рекорд, собрал витрину, закрыл башню и т.п. — присылает черновик и спрашивает «Выкладываем?».
«да» — публикует в Telegram-канал и Discord `#новости`.
«нет» — ищет дальше.

В конце каждого сообщения всегда:

`Актуальная информация всегда у нас в Telegram: https://t.me/WuwaNewss`

На Пикабу сам ничего не публикует. Старого бота новостей в Telegram не трогает.

## Как запустить

1. В Telegram: [@BotFather](https://t.me/BotFather) → `/newbot` → скопируй токен.
2. Напиши новому боту `/start`, иначе он не сможет писать в личку.
3. Скопируй `.env.example` в `.env` и впиши `PIKABU_BOT_TOKEN`.
4. `run.bat` — дежурит.
5. `run.bat --send-latest` — сразу пришлёт черновик по последнему патчу/превью.

## GitHub Actions

В репозитории `wuwa-news-bot` стоит отдельный workflow `pikabu.yml`. Секреты:

- `PIKABU_BOT_TOKEN`
- `PIKABU_ADMIN_ID` — твой user id, по умолчанию `855159275`
