# DTF рядом с Telegram-ботом

Когда Cloudflare-бот публикует новость в Telegram-канал, этот скрипт сразу делает **другой** пост в блог [Wuwa News (RU)](https://dtf.ru/id3524243).

В конце каждого поста на DTF всегда есть ссылка на канал: https://t.me/WuwaNewss

Текст не копируется один в один: для DTF отдельный рерайт.

## Секрет

В GitHub Actions:

- `DTF_TOKEN` — из профиля DTF → Инструменты разработчика
- `DTF_USER_ID` — `3524243`

Токен появляется примерно через сутки после регистрации аккаунта.
