# Ежедневный контент канала

Два поста в день в Telegram, чтобы канал не молчал между официалками.

- **утро** — коды, если вышли; иначе календарь баннеров
- **вечер** — резонатор, эхо или напоминание про русик после патча
- **среда и суббота вечером** — пост из сообщества (рекорд, коллекция, мета) со ссылкой, не официалка
- **за час до техработ** — одно отдельное сообщение
- к каждому посту случайный официальный арт
- стримы не берём

Календарь правится в `data/calendar.json` под каждый патч.

```bat
py -3 daily/poster.py --slot morning --dry-run
py -3 daily/poster.py --slot evening --dry-run
```
